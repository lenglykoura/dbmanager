A free, open-source phpMyAdmin alternative for MySQL & MariaDB

DBManager is a fast, lightweight web-based database manager with a Navicat-style layout. Browse and edit data, design tables, run SQL and export huge databases from your browser, with no framework and no build step.

Everything you need to manage a database

Built for everyday work on real databases: hundreds of tables, millions of rows.

▤

Navicat-style objects view

A grid of every table and view with rows, sizes, engine and collation. Open, design, rename, duplicate, empty or drop from a toolbar or right-click menu.

✎

Edit data in place

Double-click any cell. Dates get a date picker, numbers are checked as you type, ENUMs get a dropdown, and foreign keys show names instead of bare IDs.

⌕

Filter & sort

Contains, between, is empty, is NULL, match all or any, multi-column sort, plus a quick filter row under the headers.

⚙

Table designer

Add, edit, move and drop columns; manage indexes and foreign keys with ON DELETE / ON UPDATE rules; see which tables reference this one.

>_

SQL editor like phpMyAdmin

Syntax colours, autocomplete for every column, SELECT/INSERT/UPDATE/DELETE templates, a formatter, query history, and editable results for single-table SELECTs.

⇩

Export any size, with gzip

SQL, CSV or JSON, streamed while it is built, so a 1 GB database exports with little memory. Gzip on the fly for downloads 5–10× smaller.

⇧

Import and backups

Import .sql, .csv, .json or .gz files with a preview first. One-click server backups you can download, restore or delete.

◐

Comfortable everywhere

Dark and light themes, works on phones, and every view is a link you can open in a new tab or bookmark.

Up and running in a minute

Any PHP 8 web server with pdo_mysql works: Laragon, Herd, XAMPP, Apache or Nginx.

# get the code
git clone https://github.com/lenglykoura/dbmanager.git
cd dbmanager

# start PHP's built-in server
php -S localhost:8000
  1. Open http://localhost:8000 in your browser.
  2. Log in with your MySQL / MariaDB host, user and password.
  3. Pick a database in the sidebar and start working.
  4. Or copy the folder into your web root, e.g. C:\laragon\www\dbmanager → http://dbmanager.test.
